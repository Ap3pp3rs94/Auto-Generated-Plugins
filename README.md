# Francis Factory

Factory subsystem for generating, validating, and iterating Francis plugins.

## Purpose

This repo contains the factory code: spec generation, Station B generation, Station C validation, registry helpers, and learning hooks.

The current factory roadmap is focused on AI functionality and autonomous progress, with handoffs so each generated plugin builds on prior work instead of reinventing it.

## Run From Parent Project

```bash
cd /home/peppera091/francis
./.venv/bin/python -m factory.factory_runner
```
