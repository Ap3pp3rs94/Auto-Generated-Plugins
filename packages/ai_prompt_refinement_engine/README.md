# AI Prompt Refinement Engine

Downloadable Python plugin generated by the Auto-Generated Plugins Factory.

Version: `0.1.2`

## What It Does

The plugin analyzes a task/prompt payload and returns structured guidance for
making AI instructions clearer, safer, and easier to test.

It returns:

- `summary`
- `primary_insights`
- `recommended_actions`
- `scores`
- `details`
- `progress_state`
- `user_experience`
- `fun_mode`

Prompt-specific fields in `details`:

- `identified_vagueness`
- `missing_constraints`
- `rewrites`
- `refined_prompt`

## Use Directly

```python
import asyncio
from ai_prompt_refinement_engine import invoke

payload = {
    "task": "Create a prompt that asks an AI coding agent to add tests first.",
    "objective": "Make the instruction specific, safe, and testable.",
    "prompt": "Make this better and don't break stuff."
}

result = asyncio.run(invoke("demo-user", payload))
print(result["output"]["summary"])
```
